## 플랫폼 자체 테스트 — 1.1 사용자 로직 (`isc_post`)

연산 1.1은 `xf::cv::Sobel`와 결과 쓰기 사이에 단계 하나를 넣어, x·y 기울기 화소마다 사용자 함수 `isc_post`를 호출합니다(x·y 두 영상 모두 적용). 위 1.0 기록과는 커널 바이너리가 다릅니다.

| 항목 | 내용 |
|---|---|
| 확인일 | 2026-11-11 |
| 환경 | 위와 같음, 작업 브랜치 `feat/operation-user-logic` (커밋 전) |
| 입력 | 합성 영상 240×320 (사각 물체 + 잡음) |
| 사용자 로직 | `return g >= 60 ? g : 0;` (연산 문서 2.3) |
| C 시뮬레이션 (g++, HLS 헤더) | 시작 파일 = 1.0 커널 C 시뮬레이션과 바이트 일치. 규칙 = 1.0 결과에 같은 규칙을 적용한 값과 일치 |
| hw_emu | **통과** — 출력 = 1.0 커널 C 시뮬레이션 결과에 같은 규칙을 적용한 값 (바이트 일치). 빌드+실행 약 5분 |
| hw_emu (로직 파일 없음) | **통과** — 시작 파일(`return g;`)로 빌드한 출력 = 1.0 커널 C 시뮬레이션 결과 그대로 |
| hw (U50) | 미실행 |
| 참고 | 검증용 별도 작업 공간에서 실행했으므로 저장소의 실행 기록(`isc records`)에는 남아 있지 않습니다. 이 환경의 Python에 OpenCV가 없어 `check_output.py`(OpenCV 비교)는 실행하지 않았고, 1.0 커널 C 시뮬레이션과 비교했습니다 |

## 공식 라이브러리 테스트

**미실행** — 공식 Vision 테스트의 대상 장치에 U50이 없고(L2는 zcu104·vck190·aws-vu9p-f1), 공식 호스트가 OpenCV C++ 라이브러리를 요구하는데 이 서버에는 설치되어 있지 않습니다(관리자 권한 필요). 그래서 같은 커널 설정을 플랫폼 연산으로 감싸 7.1로 검증했습니다.

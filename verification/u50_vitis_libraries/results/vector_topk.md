## 플랫폼 자체 테스트 — 1.1 사용자 로직 (`isc_score`)

연산 1.1은 문서(행)마다 내적을 계산한 뒤, 순위를 매기기 전에 사용자 함수 `isc_score(id, dot)`를 호출합니다. `INT32_MIN`을 돌려받은 문서는 순위에 들어가지 않습니다. 위 1.0 기록과는 커널 바이너리가 다릅니다.

| 항목 | 내용 |
|---|---|
| 확인일 | 2026-11-10 |
| 환경 | 위와 같음, 작업 브랜치 `feat/operation-user-logic` (커밋 전) |
| 입력 | 연산 문서 2.1의 `docs.bin` (2,000×64 int8), `k=5` |
| 사용자 로직 | `return id < 200 ? INT32_MIN : dot;` (연산 문서 2.3) |
| C 시뮬레이션 (g++, HLS 헤더) | 시작 파일 = numpy 내적·정렬과 일치. 규칙 = numpy 내적에 같은 규칙을 적용해 정렬한 결과와 일치 |
| hw_emu | **통과** — `check_output.py` MATCH. 상위 5개 853·1443·904·1497·1522번 (규칙 없을 때 1·3·4위였던 123·79·94번이 빠짐). 빌드+실행 약 4분 |
| hw_emu (로직 파일 없음) | **통과** — 시작 파일(`return dot;`)로 빌드한 출력 = numpy 내적·정렬 그대로 (`check_output.py --original` MATCH) |
| hw (U50) | 미실행 |
| 참고 | 검증용 별도 작업 공간에서 실행했으므로 저장소의 실행 기록(`isc records`)에는 남아 있지 않습니다 |

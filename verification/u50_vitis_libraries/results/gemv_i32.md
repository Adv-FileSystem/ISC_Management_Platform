## 플랫폼 자체 테스트 — 1.1 사용자 로직 (`isc_decide`)

연산 1.1은 `xf::blas::gemv`와 결과 쓰기 사이에 단계 하나를 넣어, 고객(행)마다 사용자 함수 `isc_decide(score)`를 호출합니다. 위 1.0 기록과는 커널 바이너리가 다릅니다.

| 항목 | 내용 |
|---|---|
| 확인일 | 2026-11-10 |
| 환경 | 위와 같음, 작업 브랜치 `feat/operation-user-logic` (커밋 전) |
| 입력 | 연산 문서 2.1의 `credit_512x64.bin` (133,392바이트) |
| 사용자 로직 | `return score >= 25000 ? 2 : score >= 0 ? 1 : 0;` (연산 문서 2.3) |
| C 시뮬레이션 (g++, HLS 헤더) | 시작 파일 = `baseline.py` 점수와 바이트 일치. 규칙 = 점수에 같은 기준을 적용한 값과 일치 |
| hw_emu | **통과** — `check_output.py` MATCH. 거절 250·보류 129·승인 133명. 빌드+실행 약 5분 |
| hw_emu (로직 파일 없음) | **통과** — 시작 파일(`return score;`)로 빌드한 출력 = `baseline.py` 점수 그대로 (`check_output.py --original` MATCH) |
| hw (U50) | 미실행 |
| 참고 | 검증용 별도 작업 공간에서 실행했으므로 저장소의 실행 기록(`isc records`)에는 남아 있지 않습니다 |

## 공식 라이브러리 테스트

**미실행** — 공식 문서가 가리키는 GEMV 벤치마크(`L2/benchmarks/streamingKernel/gemvStreamCh16`)가 2024.2·2025.1 저장소에 없습니다. L3는 CPU·GPU 비교용이고, L1 `tests/hw/gemv`는 HLS 단독 시험(카드 실행 없음)입니다. 그래서 L1 테스트 top과 같은 구성을 플랫폼 연산으로 만들어 7.1로 검증했습니다.
